
# 🤖 Basic Chatbot - CodeAlpha Internship

This is a simple rule-based chatbot built using Python.

## 🎯 Objective
To create a basic chatbot that responds to predefined user inputs using conditional statements.

## 🚀 Features
- Responds to greetings
- Handles simple questions
- Loop-based continuous interaction
- Exit option using "bye"

## 🛠 Technologies Used
- Python
- Functions
- If-elif conditions
- While loop

## 🏁 How to Run
Run:
python chatbot.py
